
# Projeto B — MARV Agenda API

API REST para gerenciamento de agendamentos de serviços.

## Sobre o projeto

O MARV Agenda API é um projeto desenvolvido como trabalho final do Geração Tech 26, na trilha Full Cycle.

A aplicação tem como objetivo permitir o gerenciamento de agendamentos de serviços, oferecendo operações para cadastrar, consultar, confirmar e cancelar horários.

O projeto busca aplicar conceitos de desenvolvimento backend, arquitetura de software, princípios SOLID, testes automatizados, containerização, integração contínua, documentação e observabilidade.

## Problema

Profissionais autônomos frequentemente utilizam mensagens, planilhas e anotações para organizar seus agendamentos, o que pode ocasionar conflitos de horários, perda de informações e dificuldades de gerenciamento.

## Solução proposta

Desenvolver uma API REST que centralize o gerenciamento de agendamentos e aplique regras de negócio para garantir a consistência das operações.

## Funcionalidades

- Cadastro de agendamentos.
- Listagem de agendamentos.
- Consulta por identificador.
- Confirmação de agendamentos.
- Cancelamento de agendamentos.
- Validação de conflitos de horários.
